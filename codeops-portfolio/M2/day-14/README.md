# Ethio Telecom Dashboard Layout Clone

## Description

This project recreates the layout of an Ethio Telecom account dashboard using only HTML and CSS.

Placeholder content is used instead of real data.

## CSS Techniques Used

### CSS Grid

- Page layout
- Named grid areas
- Responsive card grid
- auto-fit + minmax()

### Flexbox

- Navigation bar
- Toolbar
- Header layout

### Other CSS

- Sticky header
- Relative + absolute positioning
- Responsive media query
- Card layout
- CSS Box Model

## Responsive Features

- Layout collapses into a single column below 700px.
- Card grid automatically adjusts columns using `repeat(auto-fit, minmax(220px, 1fr))`.
