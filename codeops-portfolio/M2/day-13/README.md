# Buna Corner Cafe - Business Profile Card

A simple business profile card for a fictional Addis Ababa cafe.

## Business

Buna Corner Cafe  
Location: Bole, Addis Ababa

## CSS Techniques Used

- CSS custom properties (`:root` variables)
- Global `box-sizing: border-box`
- Google Fonts integration
- CSS box model
- Padding, border, margin and border-radius
- Typography hierarchy
- HSL color system
- Hover and focus states
- CSS pseudo-element (`::before`)
- Responsive centered layout
