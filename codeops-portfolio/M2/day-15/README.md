# Habesha Eatery

A responsive restaurant landing page built with HTML and CSS.

## Features

- Semantic HTML5
- Sticky Flexbox navigation
- Responsive hero section
- About section
- Responsive menu grid using CSS Grid
- Reservation form with HTML validation
- Responsive design (mobile-first)
- CSS variables
- Hover transitions

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts

## Responsive

- Mobile (360px)
- Tablet (768px)
- Desktop (1280px+)
